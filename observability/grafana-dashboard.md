# ACCORDAI Grafana Dashboard Plan

## Core Dashboard Panels

### API Health
- Request count
- Error count
- Average latency
- P95 latency
- Endpoint-level latency

### AI Operations
- AI requests
- Copilot requests
- RAG searches
- Multi-agent calls

### Insurance Workflows
- Customers created
- Policies created
- Claims created
- Documents processed
- Tasks generated

### Background Jobs
- Celery queued jobs

- Celery failed jobs
- Worker availability
- Job latency

### Infrastructure
- Redis health
- PostgreSQL health
- Kubernetes pod status
- CPU usage
- Memory usage
