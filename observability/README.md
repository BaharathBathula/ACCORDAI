# ACCORDAI Observability Stack

This directory contains observability configurations and documentation for ACCORDAI.

## Planned Stack

- Prometheus
- Grafana
- Loki
- OpenTelemetry
- Alertmanager

## Monitoring Goals

- API latency tracking
- AI request monitoring
- WebSocket health
- Celery worker health
- Redis queue depth
- PostgreSQL performance
- frontend errors
- business workflow metrics
