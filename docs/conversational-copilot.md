# ACCORDAI Conversational AI Copilot

## Purpose

ACCORDAI Copilot is a conversational insurance operations assistant.

## Capabilities

- policy questions
- claims analysis
- fraud indicators
- document intelligence
- workflow recommendations
- RAG-powered knowledge retrieval
- multi-agent routing

## Architecture

User message flows through:

1. Frontend Copilot UI
2. Chat API
3. Conversation memory service
4. Multi-agent routing
5. RAG retrieval
6. Specialized insurance agent
7. Response returned to UI

## Current Agents

- Policy Agent
- Claims Agent
- Document Agent
- Workflow Agent

## Future Enhancements

- streaming responses
- persistent memory
- tenant-aware history
- citations

- workflow execution from chat
