# ACCORDAI Kubernetes Infrastructure

This directory contains Kubernetes deployment manifests for ACCORDAI.

## Services

- Frontend Next.js application
- Backend FastAPI API
- Celery worker
- PostgreSQL database
- Redis queue/cache

## Future Enhancements

- Helm charts
- Ingress controller
- Horizontal Pod Autoscaling
- Secrets management
- Observability stack
- Cloud deployment on AWS EKS, GKE, or AKS
