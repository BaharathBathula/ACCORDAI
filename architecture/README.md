# ACCORDAI Architecture

ACCORDAI is designed as a modern AI-native insurance agency management platform inspired by enterprise AMS systems such as AMS360 and Applied Epic.

## Core Architecture Goals

- Cloud-native SaaS platform
- Multi-tenant architecture
- AI-powered insurance workflows
- Modular microservice-oriented backend
- Conversational AI capabilities
- Enterprise security and governance

## Architecture Layers

### Frontend

- Next.js
- TypeScript
- TailwindCSS

### Backend

- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication

### AI Layer

- OpenAI Integration
- Policy Intelligence
- Fraud Detection
- Document Intelligence
- Conversational Copilot

### Infrastructure

- Docker
- Containerized deployment
- PostgreSQL services
- Environment-based configuration

## Future Architecture Expansion

- Kubernetes
- Redis caching
- Celery workers
- Event-driven workflows
- LangGraph orchestration
- Vector databases
- Observability stack
